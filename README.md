# 轻量启动台使用帮助

轻量启动台只保存“你的布局配置”，不移动/改写真实 App 文件。

## 一、快速开始
- 打开：点击图标或网站；键盘高亮后按 `Return`。
- 搜索：在搜索框中输入关键字、首拼或全拼。
- 退出：按 `Esc`；先关最上层子窗口，再最小化启动台。
- 多选：`⌘ + 点击` 或在空白处划区框选。
- 归类：在设置中启用「按住 ⌘ 分类整理」后，`⌘ + 拖拽` 可以创建/加入文件夹。
- 排序：直接拖拽图标调整顺序。
- 点击空白：可以清空多选、或逐层关闭子窗口最后退出启动台。

## 二、右键菜单的功能
- 空白区右键：新建文件夹 / 重建应用索引 / 设置 / 全屏 / 最小化。
- App或网站图标右键：移入文件夹 / 加入启动组合 / 固定到菜单栏；网站还可编辑或删除。
- 文件夹右键：重命名 / 解散 / 固定到菜单栏。
- 随着右键项目的不同，右键菜单项会随之变化。

## 三、菜单栏弹窗快捷启动
- 打开自定义与常用项目，不必切换主窗口。
- 顶部可切换自建目录，支持拖拽排序。
- 拖到移除区只会清除快捷图标，不会删除真实应用。

## 四、普通会员与VIP会员的区别
- 普通会员：启动台基本功能都可以永久免费使用。
- 终身 VIP：智能整理、网站快捷方式、启动组合、皮肤、布局方案、快捷键。

## 五、人工智能数据传输与安全
- API Key 只加密保存在本机的系统钥匙串中不会明文保存。
- 发起请求时，API Key 会作为身份凭证发送给您指定的 AI 服务商；使用自定义接口前，请确认该服务器可信。本机 Ollama 不需要真实 Key。
- 远程接口必须使用 HTTPS；跨域跳转会被阻止。
- AI 只接收 App 与已有文件夹的显示名和临时编号，不上传路径、Bundle ID、真实 UUID、网站 URL、使用记录或完整布局；网站与系统原生 App 的指定归类在本机完成。
- 整理结果可以先预览再应用；应用前先做好备份，支持撤销。

## 六、常见问题
- 新 App 未出现：重新激活轻量启动台；仍未出现时，在设置中点击“重建应用索引”。
- 是否会删除或改动真实 App：不会，只会改变轻量启动台中的排序与分类。
- 看不到滚动条：属于简洁化设计，可使用鼠标滚轮或触控板滚动。
- AI 整理失败：检查 API Key、网络、接口地址与模型；生成有效方案前不会改变布局。

本仓库只保存“轻量启动台”Sparkle 自动更新所需的公开文件：

- `appcast.xml`：版本清单与 EdDSA 签名

- 同名 `.md`：发布说明
- Sparkle 增量更新 `.delta`（如有）

这里不保存应用源码、用户布局、Sparkle 私钥、Apple 签名证书或服务器凭据。
