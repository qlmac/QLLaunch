# QL Launch 1.1.1（109）

- 精简系统照片图库右键菜单：照片上只显示照片操作，空白处保留刷新和切换到文件模式；两类菜单底部均保留设置和转移到显示器。
- 多选照片时隐藏单张编辑入口；另一栏不能接收照片时隐藏复制到另一栏。
- 升级源选择、检查、下载及安装确认在一个窗口内完成。下载按实际字节显示进度，解压使用真实回调，其他阶段只显示状态。
- Gitee 说明统一为“更适合中国线路”。包含 9 种语言，支持 Apple Silicon / Intel，要求 macOS 14 或更新版本。
- Developer ID 正式签名并通过 Apple 公证。

0.x 版本请下载完整安装包，完全退出旧版后手动安装一次。正式 1.1.0 版本可使用软件内更新升级。

## English

- Photo Library context menus now show only relevant photo actions. Background menus contain Refresh and Switch to File Mode. Settings and Move to Display remain available in both menus.
- Single-photo editing is hidden for multiple selections. Copy to Other Pane is shown only when the destination is available.
- Update source selection, checking, downloading and installation confirmation share one window. Progress reflects real download bytes and extraction callbacks.
- Includes 9 languages, Universal Apple Silicon / Intel support, Developer ID signing and Apple notarization. Requires macOS 14 or later.

Users of 0.x versions should quit the old app and install the full package manually once. Official version 1.1.0 supports in-app updates to this release.
