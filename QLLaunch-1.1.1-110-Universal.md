# QL Launch 1.1.1（110）

- 安装确认按钮统一为“安装并重启应用”。
- 修复更新安装并重启后，“重新检查”按钮没有反应的问题；保留升级前选择的 Gitee / GitHub 来源。
- 检查确认没有新版本时，明确显示“已是最新版”和当前版本号。
- 升级源选择、检查、下载及安装确认在一个窗口内完成；下载按实际字节显示进度，解压使用真实回调。
- 延续图库右键菜单精简，照片和空白处均保留设置和转移到显示器。
- 包含简体中文、繁体中文、英语、日语、韩语、德语、法语、西班牙语和巴西葡萄牙语，支持 Apple Silicon / Intel，要求 macOS 14 或更新版本。
- App 与 DMG 使用 Developer ID 正式签名并通过 Apple 公证。联系邮箱：admin@qlmf.com。

正式 1.1.0（106）及更新版本可使用软件内更新。0.x 版本请完全退出旧版，下载完整安装包手动安装一次。

## English

- The installation confirmation button now reads “Install and Relaunch App”.
- Fixed Check Again failing to start a new check after installation and relaunch. The selected Gitee / GitHub source is restored.
- When there is no newer version, the update window clearly states that the app is up to date and shows its current version.
- Source selection, checking, downloading and installation confirmation share one window. Progress reflects real download bytes and extraction callbacks.
- Photo Library menus keep relevant actions, including Settings and Move to Display.
- Includes 9 languages and Universal Apple Silicon / Intel support. Requires macOS 14 or later. App and DMG use Developer ID signing and Apple notarization.

Official version 1.1.0 (106) and later support in-app updates. Users of 0.x versions should quit the old app and install the full package manually once.
